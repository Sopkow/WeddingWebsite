# Ava & Bran: wedding website

Static site (plain HTML, CSS, JS) for the Jasper / Mt Robson wedding weekend, August 6–8, 2027.

## Structure
- `index.html`: the page
- `css/styles.css`: design tokens (colours, type scale) live at the top
- `js/main.js`: countdown
- `images/full`: 1800px photos, `images/thumb`: 700px thumbnails

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
GitHub Pages: repo Settings > Pages > Deploy from branch > `main` / root.
